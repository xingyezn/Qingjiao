# 青椒之梯 🌱

面向高校青年教师的科研项目与人才计划导航。覆盖国家级及中国大陆31个省级行政区，项目类别包括自然科学、社会科学、教育、博士后和人才计划；具体项目记录与官方公告入口分开维护。

网站：[青椒之梯](https://xingyezn.github.io/Qingjiao/)

## 网站

项目列表和来源目录分别维护在 `data/projects.json`、`data/sources.json`。`index.html` 和 `app.js` 负责展示地区/类别覆盖矩阵、搜索筛选、项目状态、申报时间、主管单位和原始来源链接。项目按需加载，年份筛选支持多选；正在申报的项目单独置顶展示。无需前端构建步骤。

首页使用访客 IP 粗略推测省份，将本省和国家级项目排在前面；访客可以手动选择地区。定位请求优先发往 `https://ipwho.is/`，失败时尝试 `https://ipapi.co/json/`。网站不保存 IP，仅在浏览器本地缓存省份选择。定位服务不可用或访客不在中国大陆时，国家级项目优先。

## 信息口径

- 优先采用项目主管部门、基金管理机构、规划办公室及高校科研管理部门发布的通知。高校转发仅用于国家级、省级项目；校内项目不自动当作面向全省开放的项目。
- 项目记录保留来源链接和核验日期；没有在通知中确认的申报日期留空，不根据往年惯例推测。地区目录入口不代表已核实当年具体项目或开放批次。
- 具体项目必须有 HTTPS 来源链接。2026-09-25 在当前网络逐条读取了 21 条具体项目来源，两条原链接无法打开，已换为可读取的高校科研部门通知；链接在其他地区或以后仍可能受网站限制。
- `open` 表示在申报期内，`upcoming` 表示已公布未来开放时间，`announced` 表示已发布通知但时间/批次需查看原文，`closed` 表示该年度批次已截止，`reference` 表示常设计划或等待核验当年批次。前端使用上海时区依据起止日期动态计算状态，避免数据中的旧状态让正在开放的批次漏出，也避免已过期批次继续显示为开放。
- 每周扫描执行自动审核：校验官方来源域名、HTTPS、通知年度、来源对应类别关键词和项目申报意图，并打开公告原文复核。通过规则的公告自动写入项目库；无法通过规则的线索自动忽略，不进入人工审核队列。
- 自动规则过滤结项、中期检查、评审名单、博士后站点设立等非项目申报信息，并对已有自动记录重新审核、合并同一项目的重复转发通知。能够读取高校原文时保留高校直达链接。
- 有明确申报起止日期的政府部门公告依日期自动判定为 `open`、`upcoming` 或 `closed`，不要求通知必须出现“正在申报”等特定措辞。高校通知中的校内截止日期不作为省级截止日期；来源为高校时，自动扫描不会把校内日期当作全省申报窗口。
- 高校通知中的截止日期常为校内提前截止，自动收录时不把它当作省级统一截止日期，也不自动标为 `open`。

## 每周公告扫描

Codex 桌面应用的“青椒之梯每周项目更新”定时任务每周一 09:15（Asia/Shanghai）在本地仓库运行 [项目 skill](.agents/skills/qingjiao-weekly-refresh/SKILL.md)。它先同步 `main`，检索新公告并核验来源，再调用 `scripts/codex_weekly_refresh.py publish` 运行规则扫描、校验数据并将变更推送到 GitHub。电脑和 Codex 桌面应用需在任务执行时保持运行，仓库需可访问，Git 推送凭据需有效。GitHub Actions 的自动定时触发已关闭；`.github/workflows/weekly-notice-scan.yml` 仅保留手动运行入口。

来源目录包含高校科研、社科及博士后管理部门的通知入口。扫描校验来源域名、项目意图、年度、正文及类别，并根据通知判断所属地区。登记来源不代表已经核实该地区所有类别的年度项目；新通知须通过规则审核后才进入项目库。

符合规则的新通知由本地 Codex 任务自动审核并写入默认分支；不创建审核 PR，不需要人工处理。没有数据变化时不提交。脚本只提交 `data/projects.json` 和 `data/sources.json`；本地有其他修改、远端分支已变化或扫描失败时停止发布并报告原因。

自动审核采用保守规则。Codex 负责补充检索与核验，Python 扫描器负责已登记公告页的规则检查；规则无法确认的项目不会自动标成“申报中”。少数网站采用脚本渲染、验证码或页面改版时可能无法自动读取。每周运行结果会列出成功/失败来源和自动收录数量。

## 本地维护

用浏览器打开 `index.html` 可以看静态文件，但浏览器可能限制 `file://` 页面读取 JSON。开发预览可从仓库根目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。GitHub Pages 继续从仓库当前发布分支部署；合并项目数据更新后，网站按现有 Pages 设置刷新。

## 文件结构

```text
app.js
data/
  inbox.json        # 自动发现、待人工审核的通知线索
  projects.json     # 网站展示的规范化项目数据
  sources.json      # 每周扫描来源登记表
scripts/
  weekly_scan.py    # 标准库实现的公告页扫描器
  codex_weekly_refresh.py  # 同步、校验和安全发布
.agents/skills/
  qingjiao-weekly-refresh/SKILL.md  # Codex 每周更新流程
.github/workflows/
  weekly-notice-scan.yml  # 仅手动触发
```

欢迎提交官方通知链接、项目类别或覆盖缺口。
