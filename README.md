# 青椒之梯 🌱

面向高校青年教师的纵向科研项目导航。地区覆盖国家级及中国大陆31个省级行政区，项目类别包括自然科学、社会科学、教育和博士后。国家级、上海市、北京市、广东省已收录具体项目记录；其余28个地区先建立四类官方主管部门目录入口，未核实的年度批次明确标为“参考/待核验”。

网站：[青椒之梯](https://xingyezn.github.io/Qingjiao/)

## 网站

项目列表和来源目录分别维护在 `data/projects.json`、`data/sources.json`。`index.html` 和 `app.js` 负责展示地区/类别覆盖矩阵、搜索筛选、项目状态、申报时间、主管单位和原始来源链接。无需前端构建步骤。

## 信息口径

- 优先采用项目主管部门、基金管理机构、规划办公室及高校科研管理部门发布的通知。
- 项目记录保留来源链接和核验日期；没有在通知中确认的申报日期留空，不根据往年惯例推测。地区目录入口不代表已核实当年具体项目或开放批次。
- `open` 表示在申报期内，`upcoming` 表示已公布未来开放时间，`announced` 表示已发布通知但时间/批次需查看原文，`closed` 表示该年度批次已截止，`reference` 表示常设计划或等待核验当年批次。
- 每周扫描执行自动审核：校验官方来源域名、HTTPS、通知年度、来源对应类别关键词和项目申报意图，并打开公告原文复核。通过规则的公告自动写入项目库；无法通过规则的线索自动忽略，不进入人工审核队列。
- 只有原文明确说明正在申报、提供截止日期且当前日期处于申报窗口内，才标记为 `open`；其余自动收录通知为 `announced`，不推测资格、日期或附件。

## 每周公告扫描

`.github/workflows/weekly-notice-scan.yml` 每周一 09:15（Asia/Shanghai）运行，也可以从 GitHub Actions 页面手动运行。扫描程序读取 `data/sources.json` 中登记的政府部门、项目办公室、社科联和高校公告页，寻找项目/申报/指南关键词及近年通知链接。当前来源目录覆盖国家级和中国大陆31个省级行政区的自然科学、社科、教育、博士后四类渠道；个别地区公告由党委宣传部门或项目办公室另行发布，仍需持续校准具体列表页。

符合规则的新通知由 GitHub Actions 使用仓库自带的 `GITHUB_TOKEN` 自动写入默认分支；不创建审核 PR，不需要人工处理。没有符合条件的新通知时不提交变更。定时工作流须保留在默认分支上。

自动审核采用保守规则，不调用外部 AI 服务或 API 密钥；规则无法确认的项目不会自动标成“申报中”。扫描基于已登记的公告页，不等同于全网搜索；少数网站采用脚本渲染、验证码或页面改版时可能无法自动读取。每周运行结果会列出成功/失败来源和自动收录数量。

## 本地维护

用浏览器打开 `index.html` 可以看静态文件，但浏览器可能限制 `file://` 页面读取 JSON。开发预览可从仓库根目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。GitHub Pages 继续从仓库当前发布分支部署；合并项目数据更新后，网站按现有 Pages 设置刷新。

## 文件结构

```text
app.js
data/
  inbox.json        # 自动发现、待人工审核的通知线索
  projects.json     # 网站展示的规范化项目数据
  sources.json      # 每周扫描来源登记表
scripts/
  weekly_scan.py    # 标准库实现的公告页扫描器
.github/workflows/
  weekly-notice-scan.yml
```

欢迎提交官方通知链接、项目类别或覆盖缺口。
